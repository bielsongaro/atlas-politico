# Atlas — Estudos Políticos

Projeto educacional em React, TypeScript e Vite. O módulo 15 foi acrescentado com aulas extensas sobre eleições brasileiras de 2026, leitura de planos de governo, economia, políticas públicas, checagem de alegações e argumentação eleitoral. As atividades e questões aparecem dentro do texto das aulas e também há uma atividade final com resposta comentada.

## Executar localmente

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```

O projeto não exige API paga para funcionar. O progresso e as anotações são locais ao navegador, e a área de membros usa autenticação demonstrativa, não adequada para proteger conteúdo privado em produção. As fontes eleitorais são datadas; confira as páginas oficiais para atualizações.
